# 運用コマンドリファレンス

`ops/scripts/` 配下の運用スクリプトが提供する Gulp タスクの一覧です。実行は `npx gulp <タスク名>` で行います。各カテゴリには `*:help` タスクがあり、`npx gulp dev:help` のように確認できます。

スクリプトのネーミング・実装規約は [運用スクリプト作成ガイド](../reference/運用スクリプト作成ガイド.md) を参照してください。

## アプリケーション開発（develop.js）

`apps/` 配下の各アプリケーションを Docker / Docker Compose で起動・停止・ビルドします。`up` 前に Docker secrets を `*.example` から自動生成します（taskapp は `hack/setup-local.sh`）。

### 対象アプリケーション

| アプリ | 種別 | 説明 |
| :--- | :--- | :--- |
| `echo` | Compose | 単一コンテナの最小サンプル |
| `taskapp` | Compose | 複数コンテナ構成のタスク管理アプリ |
| `case1` | Compose | ケーススタディ1 モノリス |
| `case2` | Compose | ケーススタディ2 イベント駆動マイクロサービス |
| `case3` | Compose | ケーススタディ3 ES/CQRS（Axon） |
| `case4` | Compose | ケーススタディ4 ES/CQRS（Kafka） |
| `image-bootstrap` | Docker | distroless 非 root イメージ |

### コマンド

| タスク | 説明 |
| :--- | :--- |
| `dev:<name>` | 起動（= `dev:<name>:up`、機密ファイルは自動生成） |
| `dev:<name>:up` | 起動 |
| `dev:<name>:down` | 停止・破棄（ボリュームも削除） |
| `dev:<name>:build` | イメージをビルド |
| `dev:<name>:logs` | ログを表示（follow） |
| `dev:<name>:ps` | コンテナ状態を表示 |
| `dev:image-bootstrap` | 単体 Docker アプリを起動（`http://localhost:8090/`） |
| `dev:container-kit:build` | ユーティリティイメージ（debug / simple-nginx-proxy / time-limit-job）を一括ビルド |
| `dev:help` | ヘルプを表示 |

```bash
# 例: ES/CQRS（Kafka）スタックをローカルで起動
npx gulp dev:case4
npx gulp dev:case4:ps
npx gulp dev:case4:down
```

## Kubernetes デプロイ（k8s.js）

`apps/` 配下の各アプリをローカル Kubernetes（Docker Desktop / kind 等）へ Kustomize / Helm でデプロイします。`apply` 前に kustomize の `secretGenerator` が参照する機密ファイルを自動生成します（taskapp）。

### コマンド

| タスク | 説明 |
| :--- | :--- |
| `k8s:<name>` | Kustomize で適用（= `:apply`、必要な機密は自動生成） |
| `k8s:<name>:apply` | Kustomize で適用 |
| `k8s:<name>:delete` | Kustomize リソースを削除 |
| `k8s:<name>:status` | Pod / Service / Ingress を表示 |
| `k8s:<name>:build` | `kubectl kustomize` で生成結果を確認 |
| `k8s:<name>:helm` | Helm でデプロイ（case2〜4 のみ） |
| `k8s:<name>:helm:delete` | Helm リリースを削除 |
| `k8s:help` | ヘルプを表示 |

対象アプリと namespace は `echo`(echo) / `taskapp`(taskapp) / `case1`(cargo-monolith) / `case2`(cargo-event) / `case3`(cargo-axon) / `case4`(cargo-tracker) です。

```bash
# 例: ES/CQRS（Kafka）を Kustomize でデプロイ
npx gulp k8s:case4
npx gulp k8s:case4:status
npx gulp k8s:case4:delete

# 同じ構成を Helm でデプロイ
npx gulp k8s:case4:helm
npx gulp k8s:case4:helm:delete
```

## その他の運用タスク

| カテゴリ | スクリプト | 主なタスク |
| :--- | :--- | :--- |
| ドキュメント | `mkdocs.js` | `mkdocs:serve`, `mkdocs:build`, `mkdocs:open` |
| 開発ジャーナル | `journal.js` | `journal:*` |
| シークレット管理 | `vault.js` | `vault:*` |
| SSH・踏み台 | `ssh.js` | `ssh:*` |
| コード品質（SonarQube） | `sonar_local.js` | `sonar:local:*` |

利用可能なタスクの一覧は `npx gulp --tasks-simple` で確認できます。
